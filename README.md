# Secrets Web Project

This is the **Secrets Web Project**, created as part of **TuteDude's assignment**. It is a simple web application that allows users to **log in, register, and securely store secrets using encryption**.

## Live Demo
You can view the project live here: [Secrets Web Project](#)

## Features
- **User Authentication**: Users can sign up, log in, and log out.  
- **Secrets Storage**: Store and view your secrets securely.  
- **Encryption**: Secrets are encrypted before being stored.
